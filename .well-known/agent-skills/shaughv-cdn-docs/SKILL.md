# SHAUGHV CDN Docs

How to use fonts, brand assets, motion drop-ins, and packages from cdn.shaughv.com.

This skill points you at the SHAUGHV CDN Docs, at https://cdn.shaughv.com/. When a task involves SHAUGHV CDN Docs, read the relevant page before relying on what you remember: the docs are the source of truth, and they change.

## Reading the docs

- Any page as Markdown: add `.md` to its URL (the home page is https://cdn.shaughv.com/index.md). Every page link below already points at the Markdown.
- [llms.txt](https://cdn.shaughv.com/llms.txt): every page with a one-line summary.
- [llms-full.txt](https://cdn.shaughv.com/llms-full.txt): every page in one file, for when you need all of it.
- [JSON API](https://cdn.shaughv.com/api/docs/pages.json): the page index, with each page as JSON and Markdown.

### Fonts

- [Fonts](https://cdn.shaughv.com/fonts.md): Makira and Paper Mono are the standard pair. IBM Plex Mono and Unbounded stay opt-in.
- [Makira](https://cdn.shaughv.com/fonts/makira.md): The standard SHAUGHV sans — one face for titles, interfaces, body copy, and controls.
- [Paper Mono](https://cdn.shaughv.com/fonts/paper-mono.md): The preferred SHAUGHV monospace, with eight static weights and a variable build.
- [Gail Rock](https://cdn.shaughv.com/fonts/gail-rock.md): The previous SHAUGHV monospace, retained for compatibility — a full interface voice with a true fixed-pitch grid.
- [Opt-in families](https://cdn.shaughv.com/fonts/opt-in.md): IBM Plex Mono and Unbounded stay off the standard bundle until a project asks for them.
