## Install

The combined stylesheet includes the preferred Makira + Paper Mono pair. Gail Rock remains included for compatibility with existing designs; fonts are downloaded only when used.

```html
<link rel="stylesheet" href="https://cdn.shaughv.com/fonts/fonts.css" />
```

For Paper Mono alone:

```html
<link rel="stylesheet" href="https://cdn.shaughv.com/fonts/paper-mono/paper-mono.css" />
```

```css
code, pre, .metadata {
  font-family: "Paper Mono", ui-monospace, monospace;
}
.continuous-weight {
  font-family: "Paper Mono Variable", ui-monospace, monospace;
  font-weight: 450;
}
```

## Files and weights

| Build | Formats | Weights | CSS family |
| --- | --- | --- | --- |
| Static | WOFF2, TTF, OTF | 100, 200, 300, 400, 500, 600, 700, 800 | `"Paper Mono"` |
| Variable | WOFF2, TTF | Continuous 100–800 | `"Paper Mono Variable"` |

All 26 supplied font files are hosted without changing their bytes. The variable filenames are normalized to `PaperMono-Variable`. Normal style is supplied; there is no separate italic.

Printable ASCII has fixed advances. Combining marks and some extended glyphs have different advances, so check your actual content when exact columns matter.

## OpenType features

The supplied variable font includes `zero`, `calt`, `frac`, `ss01`–`ss04`,
`cv01`, and other tags recorded in its metadata. Enable the slashed-zero option
with `font-feature-settings: "zero" 1`. Stylistic-set meanings are specific to
Paper Mono; do not reuse Gail Rock's alternate-glyph descriptions for it.

## Choosing a format

Use the family stylesheet for browsers; it prefers WOFF2. Use TTF or OTF for
compatible desktop software, retaining the license notices. Choose the
variable family when a design needs intermediate weights such as 450. To avoid
synthetic italics, set `font-synthesis: none` where the absence of an italic
face matters, or explicitly choose an italic-capable family.
