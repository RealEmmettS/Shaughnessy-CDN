Two public packages travel with the CDN. They are downloads, not site pages.

## Prompt research archive

| | |
| --- | --- |
| Address | `https://cdn.shaughv.com/prompts` |
| Redirect | HTTP 302 to the original S3 archive; its availability is separate from Vercel |
| Behavior | Redirects to the large original research ZIP |

```html
<a href="https://cdn.shaughv.com/prompts">Download prompt research archive</a>
```

## Prompt skill bundle

One HTTP response cannot reliably trigger two file downloads. `prompts-skill.zip` nests the two original skill archives so a single click stays intact.

| | |
| --- | --- |
| Address | `https://cdn.shaughv.com/prompts-skill` |
| Type | `application/zip` attachment |
| Contains | `agentic-prompt-engineering.zip` and `loop-escape.zip` |

```html
<a href="https://cdn.shaughv.com/prompts-skill" download>Download prompt skill packages</a>
```

:::note
The outer zip stores the inner archives without recompressing them. Replace a nested skill by rebuilding the outer archive and updating the expected hashes in the test suite.
:::
