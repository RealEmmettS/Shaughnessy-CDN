Two browser-ready custom elements cover the animated wordmark loop and the official loader. Both inherit `currentColor` and skip motion when the visitor asks for less of it.

## Animated brand mark

`js/animated-brand-mark.js` defines `<shaughv-mark>`. The loop is:

1. Wordmark holds
2. Undraws
3. Portrait (mustache + glasses) draws in
4. Undraws
5. Wordmark returns

```html
<shaughv-mark
  style="display:block;width:96px;height:96px;color:currentColor"
  aria-label="SHAUGHV"
></shaughv-mark>
<script src="https://cdn.shaughv.com/js/animated-brand-mark.js"></script>
```

Hold a static frame with `data-static` (the footer of the CDN website does this):

```html
<shaughv-mark data-static aria-label="SHAUGHV"></shaughv-mark>
```

A React source port also ships at `js/react/AnimatedBrandMark.jsx` for projects that already own the component tree. The vanilla custom element is the default for HTML pages.

:::tip
Color comes from CSS. Set `color` on the host. Do not recolor individual SVG paths.
:::

## Loader

`js/shaughv-loader.js` defines `<shaughv-loader>`. The portrait fills, drains, and morphs through a goo filter into a blob, then returns. Timing, paths, and geometry are part of the recipe.

```html
<shaughv-loader style="color:var(--accent);height:120px"></shaughv-loader>
<script src="https://cdn.shaughv.com/js/shaughv-loader.js"></script>
```

The loader will fetch Anime.js from jsDelivr if the page has not already loaded it. The CDN website loads Anime.js itself so the mark choreography and the loader share one copy.

## Reduced motion

Both drop-ins honor `prefers-reduced-motion: reduce`. The mark stays on the static wordmark. The loader does not run the morph loop. Keep that behavior if you wrap either element.
